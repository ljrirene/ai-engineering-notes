What to learn

低阈值通常增加 Recall，也可能增加 FPR；高阈值通常减少误报但使更多攻击漏检。没有一种单一阈值可以代替外部的权限控制。

将实验结果换算为企业运维工作量：如果每天 100,000 个正常片段、FPR 为 1%，理论上会有约 1,000 次误报。实际部署还应测量检测器延迟、跨语言泛化、Calibration 和 Adaptive Attacks。

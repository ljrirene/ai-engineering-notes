# 2026-11-09 · 简化导读和知识关系

本次修改的是阅读体验，不重新解释技术正文，不改变原始一手资料与原有选题计划。

## 回查范围与结果

- 目前知识图谱具有 **53 个节点 / 126 条语义关系**，其中 12 篇为文章节点。
- 检查全部 12 篇文章的稳定 URL、交互图链接、首页与归档入口，统一导读元数据进入 `docs/_data/studies.yml`；所有文章都有两句概要。
- 累计 22 个精选关联阅读，链接的文章 ID 均在图谱内，关联有具体理由。每篇推荐不超过 2 条，优先使用既有文章间关系。
- 首页改为最近 6 篇的双句概览，归档按相同数据源自动显示其余全部文章。新文发布时不用在多处手动复制描述。
- 文章正文保留原研究内容，通过通用 Layout 在主标题下插入双句概览及关联文章。
- 星图侧栏调整为“推荐阅读优先、概念其次、其余折叠”，不再强迫读者先理解“互补、解释、扩展”等关系术语；原来的 Type/Reason 关系数据仍然保留。
- 检查限制：验证数据 ID、元数据路径和前端 JS 语法，但尚未完成真实浏览器端到端与移动端操作验证。以 GitHub Pages 构建记录作为下一步验收。

## 后续维护

每三天一个新主题时，先回查旧文章与关系，再更新唯一的 studies.yml 两句介绍和经过事实检查的推荐链接，避免仅靠相同关键词强加连接。

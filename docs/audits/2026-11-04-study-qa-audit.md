# Study QA · 历史知识库覆盖与一致性检查

> **日期**：2026-11-04 · **变更类型**：新增无模型 API 的检索式 QA、主动回忆题库、学习指南扩展。

## 变更前检查范围
- 已读取本库知识图谱公开数据（文章、节点、typed edges）；从 `docs/notes/` 中逐篇读取 **10 篇**已归档研究，抽取真实文本，不使用模型推测内容。
- 检查文章与 Graph article 节点是否一一对应；本版 **10/10** 匹配。
- 检查所有文章能检索至少一个段落；实际建立 **81 个**检索段落，10/10 有来源文章 ID 和章节描述。
- 根据每篇文章的核心机制与失败模式手动整理 **20 道**学习自测题（10/10 篇各 2 题），各有提示、参考答案、常见误区与关键词组。通过静态结构验证题目来源 article ID 存在。
- 图谱数据保留原本类型与关系定义，不修改原有技术依赖与文章元数据；新增功能不要求更改过去 10 篇的研究观点。此前已有文章的技术事实并未在本次审计中逐个复现实证。

## 静态验收
| 检查 | 结果 |
|---|---|
| 现有文章被检索索引覆盖 | 10/10 |
| 具有来源的实际文本片段 | 81 |
| 对应来源文章 ID 的自测题 | 20 |
| 漏配来源文档、问答题、关键词组 | 0 |
| 默认无需第三方模型 API | 是；仅浏览器读本站静态 JSON |
| 提问语义推理/自动评分 | **没有**；检索与关键词覆盖不应冒充模型理解 |
| 文本是否来自 FlowMind 私人浏览器数据 | 否；未读 FlowMind 私人数据 |
| AI API Key / Token 是否存入网站代码 | 否 |

## 更新链路与下一次 Guide 变更
- 站点入口在首页、文章归档、顶栏和知识星图；问答结果带来源原文与交互架构图链接。
- 下次每三天新增文章时应同步生成新的已溯源检索切片、至少 2 道经过编辑审查的题目，并检查旧文章是否因新 Guide/术语与图谱关系发生实质变化。
- 每次新增/修正后检查 JSON ID 一致性、无孤儿问题、无截断的引用、错误的题目判断、过期链接和页面适配。
- **残余限制**：静态索引没有 Embedding/Reranker，长中文问法可能漏召回；自检只验证词面覆盖，不能替代有能力的评阅者或 LLM 语义反馈；浏览器功能需要部署完成后实际端到端测试。

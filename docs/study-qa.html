是否需要 API？

当前版本不需要。 资料搜索、问题抽取、自测与答案对照均在浏览器端完成，仅读取本站公开研究索引，不会向外部 AI 服务发送你的回答。

真正理解任意开放式回答、连续追问、动态生成个性化讲解，需要接入本地模型（如 Ollama）或受控 API。公共网站不应硬编码服务商 API Key。

FlowMind 的私人念头不会自动进入本公开知识库。
